# 启灵沙盘天梯接口

> 开发中：MCP 说明见 `MCP-OPPONENT.md`。C / C++ 源码上传和评测暂未开放；下述输入输出格式是实现目标，正式开放前可能调整。

两种提交方式使用同一套对局消息。每次请求包含：

- `phase`：`weights`（选移动概率）、`start`（选起点）或 `action`（行动）。
- `rules`：当前规则说明。
- `state`：该选手可知的局面，不包含隐藏的对方位置。
- `legalActions`：当前允许的行动编号；仅行动阶段使用。

返回的 JSON 对象按照阶段填写：

```json
{"weights":[25,25,25,25]}
{"col":4}
{"action":4}
```

概率按选手视角的上、右、下、左排列，均为至少 1 的整数，总和 100；起点列 `col` 为 0–8。行动必须选自本次提供的 `legalActions`，不能假设不同阶段的相同编号含义相同。

MCP 玩家通过 Streamable HTTP 提供 `qiling_choose` 工具，每次行动超时 100 秒。源码玩家计划使用 WebAssembly 隔离运行；输入、输出和资源限制将在评测器实现并验证后公布。
