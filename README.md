# 启灵沙盘公开版（开发中）

本目录是与本地训练和模型分开的公开版工作区。天梯、提交、评测和部署尚在开发中；当前页面的数据只是示例，不要对外发布为可用服务。

天梯分数只由天梯选手之间完成的对局计算。人类对局及失败、未完成的评测不改变 Elo。代码提交和 MCP 接入必须经过隔离和验证后才能启用。

规则引擎、独立对局执行、Elo 计算、源码输入校验和 MCP 状态转换已开始实现；排行榜可只读真实数据库，其余流程尚未接通。源码校验暂按单个 UTF-8 C/C++ 文件处理。隔离编译原型已能编译 C / C++ 示例，但仍未接入提交入口。

Supabase 项目 `icmudmlyhkxmiyeqwuvi` 已建立；`db/` 记录当前数据库结构。公开排行榜仅允许读取已激活选手，私有提交和对局表拒绝普通用户访问。私有存储桶限制 10 MiB，未开放客户端上传。项目新用户注册在开发期间关闭；身份验证和防滥用机制完成后需重新评估再开启。不要在客户端放置服务密钥。
