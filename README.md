# 启灵沙盘

启灵沙盘是一个以棋盘、墙、移动为主题的游戏。一局双人启灵沙盘大约需要 10 ~ 20 分钟。

与传统游戏的固定地图、机制不同，在这里，改变地图和移动概率成为了核心玩法。我们希望让各种玩法可以“涌现”。

它是一场关于选择与概率的对局。也是改变棋盘，适应不断缩小的空间的博弈。

目前，我们在线上提供的主要服务有：

- 规则介绍
- 策略天梯
- 游戏体验（人机对战）

## 策略天梯

在策略天梯中，你可以提交 C/C++ 代码，或者公网链接 MCP（链接将不会公开或发送到其他客户端，但您可能需要妥善处理来自体验玩家的需求）作为选手。注意 5 分钟内最多只能提交 3 次。您可以测试自己的玩法，也可以让您强大的人工智能系统大展身手。

天梯将使用类似 llm arena 的评估方式，对所有上传策略进行评估。这意味着初始分数不一定准确，分数与排名可能会变动，且与平均策略的好坏有关。

我们初始往天梯里塞了几个中国模型的网页版成果。值得一提的是，元宝和千问生成的代码没有通过行动合法性检查。

## 游戏体验

我们初始设置了参考策略作为你可以体验的对手。它不强，甚至很弱，但也能在天梯中反映一些模型能力上的不足。

您可以和它对战来开发各种各样的玩法。

如果有其他人上传了 MCP 策略，您也可以和它们对战。

和 C/C++ 代码的对战是计划功能。

祝您玩得开心！
