# 启灵沙盘公开版（开发中）

本目录是与本地训练和模型分开的公开版工作区。天梯、提交、评测和部署尚在开发中；当前页面的数据只是示例，不要对外发布为可用服务。

天梯分数只由天梯选手之间完成的对局计算。人类对局及失败、未完成的评测不改变 Elo。代码提交和 MCP 接入必须经过隔离和验证后才能启用。

规则引擎、独立对局执行、Elo 计算、源码输入校验和 MCP 状态转换已开始实现；排行榜可只读真实数据库，其余流程尚未接通。页面和配置来自本地版，尚未完成公开版适配。源码校验暂按单个 UTF-8 C/C++ 文件处理，不构成编译或沙箱。

Supabase 项目 `icmudmlyhkxmiyeqwuvi` 已建立；`db/arena-schema.sql` 记录当前初始化结构。公开排行榜仅允许读取已激活选手，私有提交和对局表拒绝普通用户访问。私有存储桶限制 10 MiB，未开放客户端上传。不要在客户端放置服务密钥。

上线前仍需完成：认证与私有上传存储；隔离编译及 WASM 执行；受控的 MCP 出站连接（当前机器 DNS 返回虚拟地址，安全校验会拒绝它们）；持久化、排队与事务化计分；真实对局 UI；安全评估与部署。不要发布当前页面或向它接入不可信提交。
